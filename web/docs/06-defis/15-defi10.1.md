# Défi 10.1 — Rapport de ventes CSV

## Contexte

Une petite boutique conserve ses ventes dans un fichier CSV nommé `ventes.csv`. Chaque ligne contient le nom du produit, sa catégorie, la quantité vendue et son prix unitaire. Le revenu d'une ligne est calculé ainsi : `quantité × prix unitaire`.

## Fichier d'exemple

```text
Produit;Catégorie;Quantité;Prix
T-shirt;Vêtements;3;18.50
Tasse;Souvenirs;2;12.00
Affiche;Décoration;5;7.25
```

## Besoins

Crée une application console qui lit le fichier CSV et produit un rapport contenant :

- le nombre de lignes de vente valides ;
- le revenu total ;
- le produit qui a généré le plus grand revenu ;
- le nombre total d'articles vendus par catégorie, en additionnant les quantités ;
- un nouveau fichier CSV ou texte qui résume les résultats.

## Notions à mobiliser

- lecture et écriture d'un fichier CSV;
- séparation des colonnes avec `Split(';')`;
- conversion des quantités et des prix, boucles et accumulations.

## Contraintes

- Ignore la ligne d'en-tête lors de l'analyse.
- Valide la quantité et le prix avant de les utiliser dans les calculs.
- Gère les lignes incomplètes sans interrompre le programme.
- Utilise les notions de fichiers, de boucles, de conditions et de structures de données vues dans le cours.

## Bonification facultative

Permets à la personne qui utilise le programme de choisir une catégorie et d'obtenir seulement son bilan.

## Critères de réussite

- Les données sont lues depuis le CSV et le rapport est exact.
- Le fichier de sortie est clair et réutilisable.
- Les erreurs de données sont signalées ou ignorées de manière cohérente.

## Tests manuels et résultats attendus

Avec le fichier d'exemple, vérifie les résultats suivants :

| Élément | Résultat attendu |
| --- | --- |
| Nombre de ventes valides | 3 |
| Revenu total | 115,75 $ |
| Produit le plus rentable | T-shirt, avec 55,50 $ |
| Articles de la catégorie Vêtements | 3 |
| Articles de la catégorie Souvenirs | 2 |

Ajoute ensuite une ligne avec une quantité non numérique, par exemple `Stylo;Papeterie;abc;2.00`. **Résultat attendu :** le programme demeure fonctionnel, cette ligne n'est pas ajoutée aux calculs et le revenu total reste `115,75 $`.
