# Défi d'intégration 13.2 — Gestionnaire de prêts

## Contexte

Le département d'informatique prête quatre exemplaires de matériel aux étudiantes et étudiants. Une application doit conserver les prêts actifs, déplacer les prêts retournés et retrouver ces informations après sa fermeture.

Chaque prêt est représenté par une chaîne au format `Nom;Matériel;Date`, par exemple `Alex;CASQUE-01;2026-09-15`. Aucune classe supplémentaire n'est nécessaire.

## Besoins

Crée une application WinForms contenant :

- un `TextBox` `Nom` et un `TextBox` `Date de retour` ;
- un `ComboBox` `Matériel` ;
- un bouton `Ajouter le prêt` ;
- une `ListBox` `Prêts actifs` et une `ListBox` `Prêts retournés` ;
- un bouton `Marquer comme retourné` ;
- les libellés `Prêts actifs` et `Prêts retournés` avec leurs nombres ;
- un menu `Fichier` contenant `Enregistrer` et `Quitter`.

Le programme doit ajouter un prêt valide dans la liste active, empêcher un double prêt, déplacer le prêt actif sélectionné vers les retours et actualiser les deux compteurs après chaque action.

## Valeurs et fichiers à utiliser

- Le nom est un texte non vide.
- Le `ComboBox` contient exactement `CASQUE-01`, `SOURIS-01`, `ADAPT-01` et `CABLE-01`.
- La date est un texte non vide au format `AAAA-MM-JJ`. Pour ce défi, vérifie seulement qu'elle n'est pas vide.
- Les prêts actifs sont enregistrés dans `C:\EspaceLabo\prets-actifs.txt`.
- Les prêts retournés sont enregistrés dans `C:\EspaceLabo\prets-retournes.txt`.
- Chaque élément d'une `ListBox` occupe une ligne dans son fichier, au format `Nom;Matériel;Date`.

Au chargement du formulaire, lis les deux fichiers et remplis les deux listes. Si un fichier n'existe pas, la liste correspondante commence simplement vide. L'option `Enregistrer` remplace le contenu des deux fichiers par le contenu actuel des deux listes.

## Notions à utiliser

- contrôles WinForms `TextBox`, `ListBox`, `ComboBox`, `Button`, `Label` et `MenuStrip`;
- événements `Click` et chargement du formulaire;
- parcours des éléments d'une `ListBox`;
- `Split(';')`, conditions, lecture et écriture de fichiers texte.

## Contraintes

- Avant d'ajouter un prêt, vérifie les trois champs. Sinon, affiche `Remplissez le nom, le matériel et la date.`.
- Un matériel est indisponible si son identifiant apparaît dans un prêt de la liste active. Dans ce cas, affiche `Ce matériel est déjà prêté.`.
- Le bouton de retour agit sur l'élément sélectionné dans `Prêts actifs`. Sans sélection, affiche `Sélectionnez un prêt actif.`.
- Lors d'un retour, déplace la chaîne complète sans en modifier le format.
- Le choix `Quitter` ferme l'application; l'étudiant doit utiliser `Enregistrer` avant de quitter pour conserver les changements.

## Exemple de résultat

**Entrées saisies :** nom `Alex`, matériel `CASQUE-01` et date `2026-09-15`, puis clic sur `Ajouter le prêt`.

```text
Prêts actifs
Alex;CASQUE-01;2026-09-15

Prêts retournés

Nombre de prêts actifs : 1
Nombre de prêts retournés : 0
```

## Critères de réussite

- Les deux listes et les deux compteurs demeurent synchronisés.
- Un matériel ne peut apparaître qu'une fois dans les prêts actifs.
- L'enregistrement et le chargement conservent exactement le contenu des listes.
- Tous les comportements sont réalisés avec les contrôles, événements et fichiers vus au cours.

## Tests manuels et résultats attendus

Commence avec les deux fichiers absents ou vides, puis effectue les tests dans l'ordre.

| Nom | Matériel | Date de retour | Action | Résultat attendu |
| --- | --- | --- | --- | --- |
| `Alex` | `CASQUE-01` | `2026-09-15` | Ajouter | `Alex;CASQUE-01;2026-09-15` apparaît dans les prêts actifs; compteurs : 1 actif et 0 retourné. |
| `Samira` | `CASQUE-01` | `2026-09-16` | Ajouter | Message `Ce matériel est déjà prêté.`; les listes et les compteurs ne changent pas. |
| Aucune saisie | Aucune sélection | Aucune saisie | Sélectionner le prêt d'Alex, puis le marquer comme retourné | La ligne passe dans les prêts retournés; compteurs : 0 actif et 1 retourné. |
| `Samira` | `CASQUE-01` | `2026-09-16` | Ajouter | Le matériel est de nouveau disponible; la ligne de Samira est ajoutée; compteurs : 1 actif et 1 retourné. |
| Aucune saisie | Aucune sélection | Aucune saisie | Enregistrer, quitter, puis redémarrer | La liste active contient Samira, la liste retournée contient Alex et les compteurs affichent 1 et 1. |
| Nom vide | `SOURIS-01` | `2026-09-15` | Ajouter | Message `Remplissez le nom, le matériel et la date.`; aucun prêt ajouté. |
| `Maya` | Aucun matériel sélectionné | `2026-09-15` | Ajouter | Même message; aucun prêt ajouté. |
| `Maya` | `ADAPT-01` | Date vide | Ajouter | Même message; aucun prêt ajouté. |
| Aucune saisie | Aucune sélection | Aucune saisie | Cliquer sur `Marquer comme retourné` sans sélectionner de prêt | Message `Sélectionnez un prêt actif.`; les listes ne changent pas. |
