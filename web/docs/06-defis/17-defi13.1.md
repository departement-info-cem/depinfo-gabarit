# Défi 13.1 — Utiliser un compte de fidélité

## Contexte

Une boutique veut offrir un programme de fidélité. Le projet de départ contient déjà la classe `CompteFidelite`, qui représente un compte et protège son solde de points. Ton travail consiste à créer et à utiliser un objet de cette classe dans une application WinForms.

Télécharge le projet, extrais-le, puis ouvre `CompteFidelite.sln` dans Visual Studio. La classe est complète; ne la modifie pas.

## Besoins

Complète le formulaire afin de :

- créer un objet `CompteFidelite` au nom de `Maya` lors de l'ouverture du formulaire ;
- afficher le nom et le nombre de points de l'objet ;
- lire un nombre entier dans la zone `Nombre de points` ;
- appeler la méthode d'ajout avec le bouton `Ajouter` ;
- appeler la méthode d'échange avec le bouton `Échanger` ;
- actualiser le nombre de points et afficher le résultat de chaque action.

## Valeurs et classe fournies

La classe expose exactement les membres suivants :

- le constructeur `CompteFidelite(string nom)` ;
- les propriétés en lecture `Nom` et `Points` ;
- `AjouterPoints(int nombrePoints)`, qui retourne `true` seulement lorsque le nombre est supérieur à `0` ;
- `EchangerPoints(int nombrePoints)`, qui retourne `true` seulement lorsque le nombre est supérieur à `0` et ne dépasse pas le solde.

Le solde initial est toujours `0` et il ne peut pas être modifié directement depuis le formulaire.

## Notions à utiliser

- instanciation avec `new`;
- utilisation du constructeur, des propriétés et des méthodes d'un objet;
- objet conservé dans une variable membre du formulaire;
- événement `Click`, `TryParse` et mise à jour de `Label`.

## Contraintes

- Ne reproduis pas les règles de points dans le formulaire : utilise les valeurs retournées par les méthodes de l'objet.
- Si la saisie n'est pas un entier, affiche `Entrez un nombre entier de points.`.
- Après un ajout, affiche `Ajout effectué.` ou `Ajout refusé.`.
- Après un échange, affiche `Échange effectué.` ou `Échange refusé.`.
- Après chaque action, le libellé `Points disponibles` doit représenter la propriété `Points` de l'objet.

## Exemple de résultat

**Actions effectuées dans l'ordre :** ouvrir l'application, saisir `100` et cliquer sur `Ajouter`, puis saisir `30` et cliquer sur `Échanger`.

```text
Compte : Maya
Points disponibles : 0

Nombre de points : 100
Ajout effectué.
Points disponibles : 100

Nombre de points : 30
Échange effectué.
Points disponibles : 70
```

## Critères de réussite

- L'objet est créé une seule fois et conservé pendant l'utilisation du formulaire.
- Le formulaire utilise le constructeur, les propriétés et les méthodes fournis.
- L'affichage demeure synchronisé avec l'état réel de l'objet.

## Tests manuels et résultats attendus

Effectue les tests dans l'ordre, à partir d'une nouvelle exécution de l'application.

| Action et valeur à saisir | Résultat attendu |
| --- | --- |
| Ouvrir l'application | `Compte : Maya` et `Points disponibles : 0`. |
| Ajouter `100` | `Ajout effectué.` et `Points disponibles : 100`. |
| Échanger `30` | `Échange effectué.` et `Points disponibles : 70`. |
| Échanger `80` | `Échange refusé.` et `Points disponibles : 70`. |
| Ajouter `-10` | `Ajout refusé.` et `Points disponibles : 70`. |
| Saisir `bonjour`, puis cliquer sur `Ajouter` | `Entrez un nombre entier de points.` et `Points disponibles : 70`. |
